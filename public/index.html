How to import into Anki
  1. Open Anki on your computer.
  2. Click File → Import.
  3. Select the downloaded flashcards.csv.
  4. The file already specifies the deck, separator, and note type — just confirm and click Import.
  5. A new deck with the name you chose will appear in your collection.
